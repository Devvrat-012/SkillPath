# Skillpath — Framer Assignment

A responsive learning platform landing page built in **Framer + React Code Components**.

### Features

* Dynamic course data from API
* INR/USD regional pricing
* Loading, error & empty states
* Retry handling
* Responsive 3/2/1-column course grid
* Framer property controls

### API

* `GET /assignment/course-data`
* `GET /assignment/country-code`
